# 👋 Привет! Я Вадим

Разрабатываю прикладные инструменты и прототипы на Python с использованием AI-инструментов и современных библиотек.

Фокус:
- 🤖 AI-интеграции (OpenAI API)
- 📊 Автоматизация и обработка данных
- 📄 Генерация PDF и отчётов
- 🤖 Telegram-боты
- 🛠 Быстрое создание MVP и утилит

---

## 🚀 Избранные проекты

### 🔹 AI AutoGeneration
AI-сервис для анализа диалогов и генерации PDF-отчётов.

- Анализ текстов через LLM
- Автоматическая генерация структурированных отчётов
- Кэширование и логирование
- WeasyPrint + Jinja2

👉 https://github.com/rustlung/ai_autogeneration

---

### 🔹 OpenAI Telegram Bot
Многофункциональный Telegram-бот с поддержкой:
- диалоговой памяти
- генерации изображений
- подсчёта стоимости запросов
- работы с файлами

👉 https://github.com/rustlung/openai_bot

---

### 🔹 PDF Tools
CLI-инструмент для:
- сжатия PDF
- объединения файлов
- оптимизации размера

👉 https://github.com/rustlung/pdf-tools
